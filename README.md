# Quadratic Equation Solver

This C program reads the coefficients a, b, and c of quadratic equations from an input file and calculates their real solutions.

It solves equations in the form:

ax² + bx + c = 0

Mathematical Formula

Delta = b² - 4ac

* Delta > 0: Two real solutions.
* Delta = 0: One real solution.
* Delta < 0: No real solutions.

Output

The calculated results are saved in solutions.txt.
